1. Objectif du site

Pourquoi ce site existe

Groupe Prolongation permet de publier et gerer des annonces de vehicules (et autres categories), puis de faciliter la prise de contact avec les acheteurs.

Le client (admin) publie les annonces.
Les visiteurs consultent les annonces et contactent via le formulaire.

4. Espace admin

Connexion et tableau de bord

  1. Ouvrir https://groupeprolongation.com/admin
  2. Saisir utilisateur + mot de passe admin
  3. Cliquer Se connecter

Une fois connecte, l admin peut:

  • Voir toutes les annonces
  • Ajouter une annonce
  • Modifier une annonce
  • Supprimer une annonce
  • Se deconnecter
Ne partagez pas les identifiants admin.
Changez le mot de passe au moindre doute.
5. Publier une annonce

Procedure simple (pas a pas)

  1. Depuis admin, cliquer Ajouter une annonce
  2. Remplir les champs obligatoires: titre, description, prix, categorie, telephone, ville
  3. Remplir les champs vehicule selon la categorie (carburant, transmission, annee, kilometrage)
  4. Ajouter les medias (URL ou upload local)
  5. Verifier l apercu des medias
  6. Cliquer Publier l annonce
Conseil: commencer avec 5 a 8 photos claires et une description precise augmente les contacts.
6. Modifier / supprimer

Gerer une annonce existante

Modifier

  1. Dans /admin, cliquer Modifier sur la ligne annonce
  2. Mettre a jour les champs necessaires
  3. Cliquer Enregistrer les modifications

Supprimer

  1. Dans /admin, cliquer Supprimer
  2. Confirmer la suppression
Une suppression est definitive. Verifier avant de confirmer.
7. Medias

Photos et videos

  • Maximum: 20 medias par annonce
  • Methodes: URL web ou upload fichier local
  • Formats images: JPG, JPEG, JFIF, PNG, WEBP, GIF, AVIF, BMP, HEIC, HEIF, TIFF, ICO
  • Formats videos: MP4, WEBM, OGG, MOV, MPEG

Bonnes pratiques medias

  • Nom de fichier simple (sans caracteres speciaux)
  • Images nettes et lumineuses
  • Montrer exterieur + interieur + details
  • Eviter des fichiers trop lourds

10. Depannage

Problemes frequents et solutions

1) Je ne peux pas publier

  • Verifier que vous etes connecte sur /admin
  • Verifier les champs obligatoires

2) Une image ne s affiche pas

  • Verifier le format du fichier
  • Re-upload le media
  • Tester avec une image plus legere

3) Erreur base de donnees

  • Verifier api/config.php (DB name/user/pass)
  • Verifier les privileges MySQL dans cPanel
En cas de blocage, contacter le support technique a support@konzotechagency.com avec capture ecran + URL + heure du probleme.
